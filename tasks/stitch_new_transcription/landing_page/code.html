Frequently Asked Questions

How accurate is the transcription?

Our engine achieves 98.4% accuracy on high-quality studio audio and 94% on mobile-recorded shorts. We use specialized models for background noise cancellation.

Do you support private videos?

No, for security and compliance, we only process publicly accessible links or manual file uploads from your device.

Can I use the API for my own app?

Absolutely. Our Pro and Business plans include full REST API access with comprehensive documentation for developers.
